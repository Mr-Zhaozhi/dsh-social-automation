# DSH Social Automation — 源码参考版

面向 macOS、DSH Desktop、NapCat/OneBot 和独立 Edge 浏览器的多平台助手工作区。提供消息接入、共享记忆、语音、浏览器任务、视频处理以及后台维护的实现参考。

这是独立脱敏仓库，不包含作者账号、API Key、音色 ID、角色素材、聊天历史、登录态、运行数据、加密备份或原始 Git 历史。代码中的 `huohuo-*` 是插件兼容标识，不代表已配置任何账号。不是 DSH、QQ 或社交平台官方项目。

## 从哪里看

- [架构与调用链路](ARCHITECTURE.md)：模块职责、消息与媒体处理流程。
- [部署与开机检查](DEPLOYMENT.md)：新 Mac 依赖、配置、双 QQ、后台服务。
- `lib/`：策略、记忆、队列、平台操作、媒体处理。
- `plugins/`：DSH 插件与事件/定时入口。
- `singing/`：可选的歌声转换适配器与依赖安装；不含模型或音频。
- `tests/`：使用模拟数据的回归测试；真实浏览器测试默认关闭。

## 能力范围

QQ/微信消息适配、主人身份绑定、群聊接话、跨平台上下文；文本转语音和本地转写；抖音/小红书/知乎浏览器操作适配；视频音轨和画面理解、视频制作；任务去重、额度和多机执行保护；页面回收、缓存清理、Mac 启动入口。

各平台能力依赖第三方插件、登录状态、权限及网页版本。部分路径有暂停或未验收边界，不能把源码中存在某个函数理解为当前平台一定可用。遇平台预警应暂停，不能通过技术手段规避限制。

## 默认状态

无账号、无密钥、无音色；主动聊天、定时任务、平台收件轮询、知乎及云端视频理解默认关闭。需要自行安装 DSH 原插件、配置模型、登录平台并明确启用。没有素材时不自动生成个人媒体内容。

只读源码无需配置账号。需要部署时从 DEPLOYMENT.md 开始，不使用作者私有仓库的同步密钥，也不执行旧的完整部署打包流程。`share/` 和 `migrate/` 保留导出、迁移实现供参考，旧一键完整包不是维护中的交付方式。

## 测试

```sh
python3 -m unittest discover -s tests
./node-run.sh --test tests/*.test.mjs
```

测试不证明真实平台登录、发布或 M1 推理效果；这些需要在使用者自己的环境验收。依赖和模型的许可证分别适用，参考 `share/THIRD-PARTY-NOTICES.md`。

原生插件集成测试依赖已安装且兼容的 DSH 插件；部分用例需显式设置 `HUOHUO_NATIVE_TESTS=1`。本次公共版默认测试跳过私人素材及外部集成；在当前机器强行启用原生测试时，表情工具指引与夜间轮询两项与安装插件不兼容，未宣称通过。
