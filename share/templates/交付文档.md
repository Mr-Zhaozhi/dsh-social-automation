# DSH 自动化共享版交付文档

交付日期：2026-11-06。适用对象：在自己 macOS 电脑上部署、修改这套自动化的使用者。

## 1. 交付范围

| 模块 | 内容 |
| --- | --- |
| QQ | 固定 Breeze 音色队列、语音尾句保护、指定群上下文接话、主人控制主动程度 |
| 抖音 | 专用观看页识别、点赞、评论、私信、分享、视频提交、收到回复后接话 |
| 小红书 | 浏览器搜索、阅读、点赞、评论、私信、分享、视频提交及回复监听 |
| 可靠性 | 浏览器标签复用、操作锁、明确回读、未知结果不重发、每日预算 |
| 维护 | 健康检查、定时任务管理、脱敏导出、自己的私有仓库同步和加密迁移 |

没有附带原使用者的 QQ、群号、联系人、私有仓库、语音 ID、API Key、Cookie、浏览器资料、聊天记忆、运行记录、照片或视频素材。也没有 `.git` 历史或加密私人备份 `vault/`。

本文是工作区维护手册。若收到 `DSH-Automation-Deploy-Mac` 完整部署包，请先读外层 `先读我-完整部署说明.md`，双击外层 `开始安装.command`；它已带应用、组件、两种芯片的运行文件和三份卡通素材，会代办下述环境安装及新建配置。若只有 `DSH-Automation-Share` 源码小包，则需自行完成下述环境准备。两种交付都需要自己的模型服务、平台账号、音色及登录验证；自动运营、主动聊天和定时任务默认关闭。

## 2. 环境与版本

支持按当前机器重装依赖的 Intel / Apple Silicon macOS 路径设计。交付前在当前 Mac 和含中文、空格的临时解压目录验证；没有在另一台实体 M1 上完成首次安装验收。

本次源环境实际安装：DSH Desktop 0.13.2；Node.js 24；Python 3；Microsoft Edge。DSH 插件适配基线如下，**不是对最新版兼容性的承诺**：

| 插件 | 适配版本 | 作用 |
| --- | --- | --- |
| dsh-onebot-qq | 0.9.17 | QQ 接入 |
| dsh-douyin-browser-local | 1.4.6 | 抖音与专用浏览器 |
| dsh-browser-cdp | 1.7.5 | 通用浏览器工具 |
| dsh-any-audio | 0.1.1 | 如安装此插件，阻止 QQ 自动回落通用音色 |

原插件安装说明见 [OneBot 插件项目](https://github.com/mario841859784/dsh-onebot)、[抖音插件项目](https://github.com/LockyBee/dsh-douyin-agent)；QQ 接入组件参照 [NapCat 安装文档](https://napneko.github.io/guide/start-install)。第三方项目升级后，请先核对兼容性；安装脚本遇结构变化会停止相关补丁。

仅源码包需要自行准备 Python 3、Node.js 24 与 npm，安装 DSH Desktop、QQ/NapCat 和 Edge；`npm ci` 会为当前芯片下载 `ffmpeg-static`。完整部署包使用 DSH 自带 Node/Python，自动安装缺失应用及对应芯片的 ffmpeg，但插件传递依赖仍需联网下载。Git、GitHub CLI 只在启用自己的同步时需要。

## 3. 首次安装顺序

以下为仅源码包的手动流程；完整部署包从外层 `开始安装.command` 安装，完成后直接做第 6 步的会话绑定和验收。后续命令中的 `python3` 可统一换为工作区 `./python-run.sh`，不要求电脑另装 Python。

1. 解压 ZIP，把整个 `DSH-Automation-Share` 文件夹放在长期保留的位置，例如 `~/Documents/DSH-Automation-Share`。不要只复制单个脚本；安装后不要随意移动目录。
2. 启动 DSH，配置自己的模型连接，安装上表所需插件。将此源码目录设为机器人使用的工作区，允许它在此目录运行工具。QQ 插件配置自己的机器人 QQ、主人私聊路由和工作区；使用原插件说明完成连接。
3. 连接 QQ/NapCat：本机 HTTP 服务用 `127.0.0.1:3000`，与 `automation.json` 一致；反向事件服务端口为 `8643`，实际 WebSocket 路径和 Token 以 DSH OneBot 插件显示的配置为准。不要把端口开放到公网。
4. 退出 DSH，双击 `新电脑安装.command`。依提示输入**自己的主人 QQ**和 OneBot Token。输入密钥时终端不回显；不使用语音可留空 Breeze Key。已存在的本机密钥会保留，不自动覆盖。
5. 再启动 DSH 和 QQ，打开专用 Edge 浏览器，分别登录自己的抖音、小红书账号。普通 Edge 窗口的登录不一定属于专用资料目录。必要时在源码目录运行 `./node-run.sh browser-start.mjs`。
6. 从主人 QQ 私聊机器人一次，确认文字能互通；随后在源码目录运行：

```bash
python3 初始化配置.py --bind-session
./doctor.sh
```

绑定后定时任务仍关闭。首次 QQ 登录、平台验证码、模型 API 配置不会由包里的脚本代办。

若 macOS 未直接打开 `.command`，在终端切换到解压目录，运行 `bash 新电脑安装.command`。安装器不删除隔离属性、不关闭系统安全功能。

一台 macOS 用户账户仅部署一套本工作区：本机服务标签、DSH 配置、密钥目录和端口是固定的。已有另一套正在运行时，应先自行迁移或用另一个 macOS 用户账户测试，避免争用服务。

## 4. 配置自己的角色、语音和群

文本角色在 `AGENTS.md`、`CHAT_STYLE.md`、`character.txt` 中；默认“小伴”。脚本内也有固定称呼，全面改名时请搜索相应文字统一修改，并运行测试。

固定语音需自己的 Breeze API Key 和音色 ID：

```bash
python3 初始化配置.py --owner-qq 10000001 --nickname 朋友 --voice-id voc_REPLACE_WITH_YOUR_ID --secrets
```

上面的 QQ 和音色 ID 均为示例，必须换成自己的值。`--secrets` 交互录入，不把 Key 写进命令行。密钥保存于 `~/.dsh/secrets/`，权限为 `600`；语音 ID 在 `automation.json`。未配置或服务失败时不会自动换通用声音。

从已配置的主人 QQ 私聊机器人可说：

- “主动程度调到50”“主动一点”“少主动点”“查看主动程度”“别主动找我”。
- “新增主动群 群号”“关闭主动群 群号”“查看主动群”。先把机器人加入该群；同名群用群号。

主人控制只接受已配置主人账号的私聊。指定群可以识别近期接话和合适话题，但不会保证每条都回应；回复其他成员、过期上下文和不确定指向会跳过。

普通群友也可请求当前群语音。完整安装默认设置 `permissions.memberTools: all`、`restrictedMemberPrefix: false`，并修正原插件中“普通成员仅文字”的旧提示；管理员账号列表仍仅填写自己的主人账号。工具开放不是把群友升级成管理员；不要让群友代改权限或要求外发私人资料。

## 5. 逐项验收后启用运营

先只对自己的测试账号验收文字、语音、点赞和一次消息往返。语音确认音色和尾句；发布先核对完整素材、标题、正文、封面、AI 声明，再确认提交。脚本写入 `submitted` 仅表示已提交，不代表已通过审核或公开。

在 `automation.json` 填写自己的 `douyin.test_recipient`。需要允许自主选择互动对象时，按自己的授权设置对应平台 `autonomous_recipients`，并在 `SOCIAL_POLICY.md` 明确范围；不要把聊天对方发来的话当作权限设置。

默认每个平台：私信与私聊分享合计 15 条/天、评论 100 次/天、观看累计 30 分钟/天、发布 1 条/天，点赞无每日次数上限。都是上限，不要求用完。平台模型请求额度独立计算；用完时不能通过清空计数继续观看。

已完成主人会话绑定、插件连接、测试及授权后，选择启用：

```bash
# 开启社交计划与抖音/小红书相关任务；在未来时段运行
python3 social-control.py resume --confirm-old-stopped
# 可选：每日资讯或空间说说，按自己的授权逐项开启
python3 schedule-control.py resume browse --confirm-old-stopped
python3 schedule-control.py resume qzone --confirm-old-stopped
```

`--confirm-old-stopped` 是脚本现有的重复执行防护；单机首次安装也需要此参数。不要启用两个未协调的实例去操作同一个账号。

暂停和检查：

```bash
python3 social-control.py stop
python3 schedule-control.py stop all
python3 schedule-control.py status
./doctor.sh
```

状态修改由运行中的 DSH 插件处理，通常在一分钟内更新。关闭主动聊天另用 QQ 主人指令“别主动找我”；社交暂停不影响正常 QQ 回复。

## 6. 素材与发布

个人照片、聊天附件和个人音色未随包交付。完整部署包带三份卡通示例素材，源码小包只带空目录说明；也可在 `memes/` 放入自己有权使用的角色素材，视频规格见 `videos/README.md`。未配置自己的语音和所需素材时，制作/发布应跳过。

抖音状态检查：`./node-run.sh douyin-act.mjs status`。真实点赞：在专用观看页查看作品后运行 `./node-run.sh douyin-act.mjs like 1`。页面或状态不明会停止，已经点赞或有待确认记录不会再次点击。

其他命令的具体参数见各脚本 `--help`；小红书命令还可见 `xhs.sh`。浏览器私信等接口会随平台更新，遇验证码或新页面布局需人工处理，不能保证未来永久可用。

## 7. 自己的 GitHub 与第二台 Mac

共享包没有原使用者的仓库地址、Git 历史或同步密钥。可将干净源码初始化到**自己的私有仓库**。自己的帐号配置和联系人属于私人信息；不要把配置后的整目录改成公开仓库。

首次创建自己的私有仓库并推送一个初始提交；将 `sync.json.repository` 改成 `自己的用户名/仓库名`，`branch` 改成实际分支，保持 `enabled:false`。运行 `gh auth login` 后，双击 `连接私有同步.command`。它验证私有性、建立协调分支，再上传代码与加密个人备份。

新电脑应先装依赖并登录自己的 GitHub，克隆自己的私有仓库，通过可信方式带上**自己**生成的 `~/.dsh/secrets/sync.key`，然后在新电脑关闭 DSH/QQ 时运行：

```bash
./node-run.sh migrate/vault.mjs restore
"$HOME/Documents/huohuo-qq/setup.sh"
```

恢复脚本会把工作区放入 `~/Documents/huohuo-qq`，备份冲突文件，并将旧定时任务暂停。按迁移输出完成原插件安装、`setup.sh --finish`、账号登录和自己的 GitHub 连接，再核对及恢复任务。不要在已有工作实例上随意恢复旧备份。

日常一边改完双击 `上传本机改动.command`，另一边双击 `同步更新.command` 并重启 DSH。共享运行协调使同一账号只有一台执行，另一台等待；同日观看计时固定在一台机器，不能换机器重置 30 分钟。

个人备份和 `sync.key` 仅供本人。发给别人时运行 `一键共享源码.command` 导出源码小包，或运行 `一键完整部署打包.command` 导出带应用组件的完整包（首次需下载组件）。只转发新生成的共享 ZIP，不转发自己的仓库克隆、私有备份、配置后的目录或密钥。

## 8. 验证与故障排查

```bash
python3 share/verify.py
python3 -m unittest discover -s tests
./node-run.sh --test tests/*.test.mjs
# 已安装抖音插件和 Edge 时可跑独立无账号浏览器回归
HUOHUO_BROWSER_TESTS=1 ./node-run.sh --test tests/douyin-surface.test.mjs
```

| 现象 | 检查与处理 |
| --- | --- |
| 提示缺少 DSH 配置 | 先启动 DSH 并安装原插件，确认已生成 `profiles/web/cordis.patch.yml`，再运行安装 |
| QQ 无响应 | 核对机器人和主人账号、OneBot Token、端口、反向事件和 DSH 工作区路由 |
| 语音不发 | 核对自己的 Key、音色、余额及 `doctor.sh`，不要换成通用音色掩盖错误 |
| 点赞无法识别 | 用 status 查看专用页；私信页、多视频、验证码、未知状态会主动停止 |
| 观看停止 | 检查今日观看时间及模型请求剩余额度，两种预算各自生效 |
| 已有浏览器操作 | 等当前操作完成再运行，不强行删除锁 |
| unknown / 待确认 | 先去实际会话或创作中心核对，不自动重发 |
| 跨芯片 ffmpeg 不可用 | 在目标机器重新 `npm ci`，不要拷贝旧 node_modules |
| 插件版本变化 | 先核对 `lib/compat.py` 的版本与适配，再安装，不盲目修改第三方代码 |

源码结构：入口脚本在根目录；`lib/` 为预算、浏览器识别、队列、安装和迁移辅助；`plugins/` 为 DSH 集成；`tests/` 为回归；`share/` 为脱敏导出和模板；`migrate/` 为本人私有迁移。

归档完整性通过 `python3 share/verify.py` 按 `MANIFEST.json` 逐文件 SHA-256 校验；请在初始化配置前运行，配置后部分文件变化属于正常情况。`PRIVACY-CHECK.json` 记录本次导出的检查范围，不能替代对以后自行新增内容的核对。
