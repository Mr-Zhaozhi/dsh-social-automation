# DSH 自动化共享源码版

面向 macOS 的 DSH Desktop 扩展工作区，包含 QQ 固定音色语音、指定群上下文接话、主动聊天、抖音及小红书互动、页面复用、收件回复、预算去重和本人多机同步代码。

本包已经去除原使用者的账号配置、密钥、聊天记录、登录态、私有仓库信息和个人素材。默认角色名为“小伴”，所有主动任务关闭。

**从 [交付文档.md](交付文档.md) 开始。** 如果外层目录为 `DSH-Automation-Deploy-Mac`，请双击外层 `开始安装.command`，由完整包安装应用、插件并新建配置。如果只有本源码目录，需先自行安装依赖，再运行 `新电脑安装.command`。两者都要使用自己的模型、平台账号和登录。

- `初始化配置.py`：填写主人账号、自己的语音配置、绑定主人私聊会话。
- `doctor.sh`：查看真实服务状态。
- `一键共享源码.command`：重新生成脱敏源码 ZIP。
- `一键完整部署打包.command`：下载公开组件并生成完整联网部署包。
- `本人私有备份.command`：仅给自己迁移，生成的文件含个人数据，不能转发给别人。
- `MANIFEST.json`、`PRIVACY-CHECK.json`：文件校验与本次导出的隐私检查说明。

源码保留 `huohuo-*` 作为兼容旧插件的技术标识；它不是 QQ 号、账号、仓库或密钥。仅源码版不带第三方应用；完整包的公开组件位于外层 components，并附第三方来源和许可说明。
