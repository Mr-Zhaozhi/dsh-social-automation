# 新电脑完整部署包

适用于 macOS 13 及以上，包括 Apple Silicon（M1/M2/M3 等）和 Intel。请把整个压缩包发给接收者，解压后双击 **开始安装.command**。

## 这次带了什么

- DSH Desktop 0.13.2 的 M 系列和 Intel 原始安装归档；应用自带 Node.js 与 Python，无需先装 Homebrew。
- 腾讯 QQ 和 Microsoft Edge 的官方安装文件；已安装的应用保留，不覆盖。
- NapCat 4.18.42、两种芯片对应的 ffmpeg、固定版本 OneBot/抖音/通用浏览器/音频插件原始包。
- 全部工作区源码、QQ 与 NapCat 的新建配置向导、后台语音/健康检查、群接话、社交互动和迁移代码。
- 两张卡通角色 PNG、一份动态 GIF，可用于表情与视频制作；没有真人照片或聊天附件。
- 详细交付文档、组件来源、文件校验清单和脱敏说明。

这是完整的**联网部署包**：主体安装文件已带齐，插件的传递依赖仍由 DSH 官方安装器联网解析，以保持宿主和插件模块一致。不要把它理解为完全断网可安装。应用、插件、账号登录、模型调用也各自需要网络。

## 为什么之前有 100 MB，这次源码却很小

之前的大包是本人迁移备份，主要体积来自约 32 MB 聊天附件、约 43 MB 图片/表情素材、约 8 MB 会话历史及截图等。它本身没有完整的 DSH、QQ、Edge 和跨芯片运行环境。

小包只包含程序文本和空白配置，约几百 KB 属于正常源码体积，但不适合直接交给完全没部署过的人。本包把应用、组件、素材及新建配置流程补上，因此会明显更大；不会用私人聊天资料填充体积。

## 安装顺序

1. 解压，双击 `开始安装.command`。若终端未自动打开，可右键用终端打开，或在该目录执行 `bash 开始安装.command`。不要删除包里的文件。
2. 安装器按实际芯片选择 DSH；需要写入 Applications 时，macOS 可能显示管理员密码框。这是系统安装授权；不要把密码交给聊天机器人。
3. 填入自己的主人 QQ 和另一个机器人 QQ。程序生成新的 OneBot Token，并同时写入 DSH/NapCat，本包不附带任何人的 Token。
4. 程序安装 QQ、Edge、固定版本插件与 NapCat，创建工作区 `~/Documents/DSH-Automation-Share`。固定组合中浏览器插件的旧版兼容声明例外只适用于已检查的 DSH 版本，不会放行任意未来版本。
5. 需要固定音色时填自己的 Breeze Key 与音色 ID；可以暂时留空，但语音/配音制作会等你补齐，不能借用原使用者的凭据或克隆音色。
6. 打开 DSH 配置自己的模型连接；运行工作区 `start-bot.sh`，完成机器人 QQ 扫码。打开专用 Edge，登录自己的抖音和小红书。
7. 从主人 QQ 私聊机器人一次，在工作区运行 `./python-run.sh 初始化配置.py --bind-session`，再运行 `./doctor.sh`。确认文字、群语音、浏览器连接正常后，按工作区 `交付文档.md` 启用自己想要的运营功能。

所有自动运营、主动找主人聊天和定时发布初始关闭。普通群成员默认可以请求当前群的语音/图片等正常互动；修改配置和管理指令仍由主人控制。新增主动群可给主人私聊机器人发送“新增主动群 群号”。

## 安装保护与中断恢复

安装器遇到已有其他主人、另一工作区的后台服务、已有不属于本次安装的 QQ 配置时会停止，不覆盖。一个 macOS 用户账户只运行一套；请在新环境或独立的 macOS 用户账户中部署。

依赖下载失败后可重新运行，已安装应用和本次配置保留。Edge 原始包若带有会影响签名检查的 Finder 属性，安装器只在临时副本移除 FinderInfo/ResourceFork，保留系统隔离属性，再严格验签。校验不通过的组件不会安装；不要清除校验或换成来路不明文件。QQ、模型和平台登录必须由接收者完成。

安装后实际运行文件在 Documents 工作区。组件归档内没有个人资料；**配置后的工作区、用户目录和自己的私人迁移包会有私人数据**，再次分享时应重新导出脱敏包。

## 验证边界

普通群成员请求语音已由真实群友验证；本地发送记录也确认群语音成功。新机流程在空白 DSH 配置目录、中文空格路径、安装配置测试中验证，组件按官方摘要核验。没有另一台实体 M1 完成账号登录、QQ 注入及全套应用首次启动验收；不能把静态架构检查说成 M1 实机通过。

QQ/平台页面、DSH 插件、macOS 权限会随版本变化。遇到登录/验证码时由账号本人处理；遇到组件版本变化先核对兼容性，不自动绕过系统验证。具体模块命令、额度和同步方式见 `workspace/交付文档.md`。
# 语音识别与连续浏览更新

包内增加 SenseVoice INT8 语音模型。安装程序为当前 Mac 芯片建立独立 Python 环境，并联网安装固定版本识别依赖。QQ 收到语音后先转写，再在原发送者的会话中回答；抖音本地转写复用同一识别引擎。通过 `./doctor.sh` 的 speech_to_text 项检查引擎。

小红书使用 `./xhs.sh browse 3` 连续滚动三屏，核对可见笔记变化；无新消息不重开旧私信。抖音同一作品连续观察四次或停留九十秒后尝试下一条，并核对作品编号。每日时间、评论及私信额度仍然生效。

引擎或模型缺失时运行 `./python-run.sh lib/setup_stt.py`，然后重启 DSH。模型可跨 Intel/M1 共用；识别依赖按芯片重新安装，不能复制另一芯片的虚拟环境。首次安装后仍须登录自己的账号，并按下面说明启用自己需要的自动化。

浏览器并发：私信、通知与浏览任务在操作前最多排队等待 30 秒，避免定时任务撞点后反复错过回复；超过时间保留队列交给后续检查，不重试已经发出的消息。
